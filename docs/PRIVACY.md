# 隐私与本地配置

公开源码不包含设备所有者的 MAC、局域网地址、账号、Token、私人邮箱或电脑绝对路径。Android 包名保留，以兼容已有安装；Git 提交使用 GitHub noreply 邮箱。

设备目标从手机本机档案、用户选择和加密配置中解析。一个匹配的 Vont 可复用已有档案；多个匹配设备需要选择。挂灯继续核对授权配置中的 MAC 与真实设备响应，不把任何人的设备地址写在公共常量里。

`.gitignore` 排除了本机配置、导入凭据、设备档案、日志、导出、密钥、构建目录与模拟器。历史私人工作目录没有复制进本仓库，也没有写入 Git 历史。仅忽略文件不能保护源码内的字面量，因此提交和发布物还需运行隐私扫描。

`tools/privacy_scan.py` 检查非忽略源码和指定 APK／ZIP 中的私人路径、常见私人邮箱、访问令牌、MAC 与局域网地址。测试中允许明确的合成地址；可用 `--denylist private/privacy.local.json` 加载额外私人阻止列表，格式为 `{"values":["需要阻止的值"]}`。报告只列文件和规则，不打印命中内容。

请勿在 Issue 或截图中提交登录信息、导入 JSON、二维码、真实设备档案或完整网络日志。设备导出可能包含地址与状态，分享前需要脱敏。发现问题时可先私下联系仓库维护者，不要公开粘贴密钥。
